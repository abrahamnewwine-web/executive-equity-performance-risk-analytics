# Agile Epics, Features & User Stories — Executive Equity Performance & Risk Analytics

- **Epic 1 (Market Data Pipeline):** Ingest and align 370 trading days for 5 equities into SQLite (`US-101`).
- **Epic 2 (Reconciled Financial Engine):** Reconcile Total Return %, CAGR %, $10K growth, Volatility %, Max Drawdown %, and Sharpe Ratio (`US-201`).
- **Epic 3 (4-View Executive Dashboard):** Provide interactive Executive, Performance, Risk, and Insight views with ticker/calendar slicers (`US-301`).
